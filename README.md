# 💰 Daily Expenditure Calculator (CLI-Based)

## 📌 Description
This project is a command-line based Daily Expense Tracker built using Python.  
It helps users manage their daily expenses by allowing them to add, view, delete, and calculate total expenditure.  
The data is stored in a file to maintain persistence across sessions.

---

## 🎯 Features
- ➕ Add new expenses with name and amount
- 📄 View all recorded expenses
- 🧮 Calculate total expenditure
- 💾 Save expenses to a file (`record.txt`)
- ❌ Delete specific expense entries
- 🔁 Persistent storage (data saved between runs)

---

## 🧠 Concepts Used
- File Handling (read/write)
- Dictionaries
- Functions
- Loops and Conditional Statements
- Exception Handling

---

## 🛠️ Technologies Used
- Python (Core Python)
- Command Line Interface (CLI)
